###  Цель работы
Изучить влияние частоты дискретизации и разрядности АЦП на частотные характеристики сигнала, освоить прямое и обратное преобразования Фурье, а также переходы между временным и частотным представлениями сигналов.

#### Пункты 1–7 (`sms1.py`)
**Вариант 17:** `y(t) = 12·cos(2π·14·t + π/6)`, `f = 14 Гц`

- Максимальная частота в спектре: **14 Гц**
- Минимальная частота дискретизации (теорема Котельникова): **fs ≥ 28 Гц**
- Выбранная частота дискретизации: `fs = 3·f = 42 Гц`, затем увеличена в 4 раза → `fs = 168 Гц`

###  Выводы

1. Теорема Котельникова (Найквиста) подтверждена: при `fs < 2·f_max` восстановление сигнала невозможно — возникает алиасинг.
2. Прямое ДПФ позволяет корректно перейти из временной области в частотную; для вещественного сигнала спектр симметричен, достаточно отображать диапазон `[0, fs/2]`.
3. Увеличение разрядности АЦП снижает ошибку квантования и уровень шума в спектре, но требует большего объёма памяти.
4. Голосовой сигнал содержит значимые компоненты до ~4–6 кГц, поэтому стандартная частота дискретизации 44.1 кГц (или 8 кГц для телефонии) является достаточной.
